# Victory View Hotel & Suites

A responsive five page static website for Victory View Hotel & Suites in Udu, Delta State. Built with plain HTML, CSS and browser JavaScript so it can deploy directly to Vercel or any host configured with root-level paths, without an application server or runtime dependencies.

## Preview and edit

- Run `npm run dev` and visit **http://127.0.0.1:4178**.
- Run `npm run build` to regenerate `dist/`.
- Run `npm run check` to validate routes, local assets, metadata and booking links.
- Edit page content in `index.html`, `rooms/index.html`, `conference/index.html`, `contact/index.html`, and `gallery/index.html`.
- Shared styles and mobile navigation live in `assets/styles.css` and `assets/app.js`.

## Deploy

Push the project to GitHub and import it into Vercel. The included `vercel.json` builds the static output in `dist/`. For a different root-level static host, run `npm run build` and publish the contents of `dist/`. Project-subpath hosting such as a GitHub Pages repository URL needs a configured custom domain or a base-path update.
